Hospital Patient Record Aggregation

Project Overview

This project focuses on collecting, cleaning, processing, and aggregating hospital patient records using Big Data Analytics.

Objectives

- Collect hospital patient data.
- Clean missing and duplicate records.
- Aggregate patient information.
- Generate useful analytical reports.

Technologies Used

- Python
- Pandas
- NumPy
- CSV Dataset
- Big Data Analytics

Project Structure

- Dataset – Patient records CSV files
- src – Python source code
- output – Aggregated results
- requirements.txt – Required libraries

How to Run

1. Install Python.
2. Install dependencies using "pip install -r requirements.txt".
3. Run the main Python file.
